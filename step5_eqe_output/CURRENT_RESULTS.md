# 現行の計算結果（2026-10-27）

長文評価のhard境界を50%未満・150%超に更新し、中国語81回答・405裁判単位の再判定を元のPenalty CSVへ反映しました。空回答・失敗回答と長さhardの確定判定も保存判定に同期しています。裁判重みは100件校正の従来値を固定しています。

現行の首位は、EQがQwen3-30B-A3B Q4（90.7002）、EQEEがGemma3-4B Q4（825.9255 EQ/MJ）です。更新前の結果との比較とバックアップは`../revision_20261027_length_sync/`にあります。閾値単独の効果を分離した比較とは区別しています。

このディレクトリは、原始データと保存済み判定から再計算した現行結果です。
勝敗校正・減点校正は各100件、対象は22構成×2回×5区分＝220セルです。

再計算は、作業ディレクトリによらず次の入口から実行します。

```powershell
python "研究関連\run_pipeline.py"
```

再計算ではモデル/APIの再呼び出しを行いません。Step2.1の現行判定を入力とし、Step2.2の保存済み比較と原回答も保持します。Step3で同一質問と双方の回答本文を照合し、Step4で空回答・失敗マーカー・長さhardの確定規則を適用します。再計算にaudit/recheckの出力は使用しません。論文用の保存値は計算後の照合にのみ使用します。

主な出力：

- `final_rankings.csv`：22構成の最終EQ・EQEEと順位。
- `repeat_scores.csv`：各回の5区分平均。
- `eqee_cells.csv`：220セルのWA・WP・Q_total・エネルギー・EQEE。
- `energy_cells.csv` / `energy_task_windows.csv` / `energy_source_checks.csv`：原電力記録の積分結果・時間窓・入力確認。
- `pipeline_verification.json`：件数、出典ハッシュ、論文保存値との数値照合。
- `chart_data/`：現行結果の図用CSV。プロジェクト直下の`chart_data/*.csv`にも2026-10-27時点の値を同期しています。同フォルダの画像・Originファイルは旧版です。

EQEEの単位はEQ/MJです。互換列`EQE_total`と`EQE_gpu`はEQ/Jで、`EQEE = EQE_total × 10^6`です。最終スコアは区分ごとの比率を平均し、合計エネルギーで平均EQを割る方法には置き換えていません。

Step5は失敗した要求も含めて原記録の開始・終了時刻を使用し、Step3の保存済み補記所要時間が利用可能な場合はそれを終了時刻に反映します。補記の記録時刻を実行時刻として用いていません。除外したコード生成課題の時間窓は加算せず、保持した課題の時間窓の和集合を積分します。重複は再構成した時間窓に関するもので、実行が並行したことを意味しません。電力記録端点の補外は1.5サンプリング周期以内に限り、該当行を出力します。

校正100件は全件有効です。一方、本評価のStep3では同問7040判定を選択したうち、1件だけ保存ラベルが双方向とも無効のため、既存規則どおりその判定を平均から除外します。選択結果は`step3_ability_output/workflow_selected_items.csv`、両方向無効の一覧は`unusable_judgement_items.csv`に保存します。空回答の6件が校正から欠落した問題とは別の記録です。
